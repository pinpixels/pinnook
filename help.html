Pinnook Help

Pinnook keeps private notes, tags and projects on top of any web page, in your browser's side panel. Everything is stored on your own device. There is no account, no sign-up and no tracking.

Quick start

  1. Click the Pinnook icon in the toolbar (use the puzzle-piece menu to pin it). The side panel opens on the right.
  2. Open any web page. The This page tab shows its title and site.
  3. Start typing in the Note box. Pinnook saves automatically after a short pause — you will see Saved ✓.
  4. Optionally pick a Project and add Tags.
  5. Open the Library tab to find everything again, grouped by project and site.

Pinnook only keeps notes for normal web pages (addresses beginning with http:// or https://). Browser pages such as chrome://settings, the New Tab page and local files cannot be saved.

Taking notes

Notes are written in Markdown, a simple way to format text. Use Write to type and Preview to see the result.

You typeYou get
# Heading, ## Smaller headingHeadings
**bold** and *italic*bold and italic
~~removed~~removed
` code `code
- item or 1. itemBullet / numbered list (indent with two spaces to nest)
- [ ] task and - [x] doneChecklist
> quoteQuotation block
[label](https://example.com)Link (only http, https and mailto links are allowed)
---Horizontal line
Three backticks on their own lineCode block

Safety notes: raw HTML is never rendered, images are not embedded, and scripts can never run from a note.

One note per page. Pinnook identifies a page by its address, ignoring the #section part and common tracking parameters (such as utm_source and fbclid). Visiting the same article through a newsletter link or a search result therefore finds the same note.

Removing a page deletes its note and tags from Pinnook (the web page itself is unaffected). The button asks you to click twice so you cannot do it by accident.

Projects and the “Working on” menu

A project is a topic or piece of work, for example Kitchen renovation, Q3 vendor research or Thesis chapter 2.

  • Use Working on (top of the panel) to choose your current project. Every new page you save is filed under it automatically.
  • Click + to create a project (give it a name and a colour).
  • Pinnook is context-aware in a simple, predictable way: if you have no active project, a new page is suggested to the project you most often used for that same website.
  • Change a single page's project with the Project menu on the This page tab.
  • Rename, recolour or delete projects in Settings → Projects. Deleting a project never deletes notes; they move to No project.

Tags

Type tags separated by commas (pricing, competitor, to-read). Tags are lower-cased, spaces become hyphens, and # is optional. Your most-used tags appear as one-click chips under the box and as filters in the Library.

The Library

The Library tab lists every saved page.

  • Search looks in titles, addresses, notes, tags and project names. Several words must all match.
  • Group by: project → site (default), site, or recent (newest first).
  • Filter by project, and click tag chips to narrow further.
  • Click an entry to expand it: you see the rendered note, an Open page button (it switches to a tab that already has the page open) and Remove.
  • Click a group heading to collapse or expand it.

Quoting text from a page

Select text on any page, right-click, and choose Add selection to this page's Pinnook note. The text is appended to the note as a quotation, and the side panel opens. The right-click menu on the page (or on the toolbar icon) also offers Save this page to Pinnook.

The badge: “this page has a note”

When you are on a page that has a Pinnook note, a small green dot (●) appears on the toolbar icon, so you never forget you already researched something. The badge is computed on your device from your own saved notes.

Keyboard shortcut

Alt + Shift + N saves the current page and opens the side panel. To change it, go to chrome://extensions/shortcuts.

Settings

Open Settings with the ⚙ button in the panel, or from the extension's details page.

  • Theme: match your system, light or dark.
  • Never save these sites: one domain per line (for example your bank or your company intranet). Subdomains are included. Pinnook stores nothing for these sites, shows no badge on them, and the panel says so.
  • Projects: rename, recolour, delete.
  • Your data: export, import, delete everything.

Export, import and moving to a new computer

  • Export JSON creates a complete backup file of your notes, tags and projects.
  • Export Markdown creates one readable document grouped by project, handy for sharing or for other note apps.
  • Import JSON merges a previous export into what you have. If both contain the same page, the most recently edited version wins; nothing is deleted.

Important: the data lives in this browser profile. Uninstalling Pinnook, or clearing the extension's data, deletes it. Export a backup from time to time — or use Premium encrypted backup.

To move to a new computer without Premium: Export JSON on the old one, install Pinnook on the new one, then Import JSON.

Premium: encrypted backup and sync

Premium keeps your notes backed up and in sync across your own devices using your own Google Drive or Dropbox. Everything is end-to-end encrypted on your device before it is uploaded, using a passphrase that only you know.

How it protects you

  • Your notes are encrypted with AES-256-GCM. The key is derived from your passphrase with PBKDF2 (SHA-256, 600 000 iterations) and a random salt.
  • The passphrase is never stored on disk and never sent anywhere. (Optionally it is kept in memory until you close the browser, so you don't retype it.)
  • Google or Dropbox only ever see an unreadable file called pinnook-backup.enc.
  • Pinnook has no servers. The developers cannot read, recover or reset your data.
  • If you forget the passphrase, the backup cannot be recovered by anyone. Keep it in your password manager.

Setting it up

  1. Open Settings → Premium.
  2. Activate your license key (paste the key from your purchase email). It is checked on your device; no server is contacted.
  3. Choose Google Drive or Dropbox and click Connect. Your browser asks for permission, then shows the provider's own sign-in screen.
    • Google Drive uses the narrow drive.file permission: Pinnook can only see the single backup file it created. Requires the Google Chrome browser.
    • Dropbox uses a private App folder (Apps/…): Pinnook can only see its own folder.
  4. Choose a passphrase (at least 12 characters; a few random words works well) and tick the acknowledgement.
  5. Click Back up & sync now.

On your other devices

Install Pinnook, activate the same license, connect the same provider account, enter the same passphrase and click Back up & sync now. Notes from both devices are merged: for each page the most recently edited version wins, and pages you deleted stay deleted.

Good to know

  • Sync is manual (button) in this version. Press it when you finish a research session and when you start on another device.
  • Two devices syncing at the very same moment cannot lose data permanently: each device keeps everything it has and the next sync merges it back.
  • To stop using it: Disconnect, then delete pinnook-backup.enc from your Drive (or the Dropbox app folder) if you want it gone.

Privacy and permissions

Pinnook asks for as little as possible:

PermissionWhy it is needed
Read your browsing activity (tabs)To read the address and title of the tab you are looking at, so the panel can show and save that page's note. Pinnook does not read your browsing history, does not record pages you do not save, and cannot read page contents.
Side panel (sidePanel)To show Pinnook beside the page.
Storage (storage, unlimitedStorage)To keep your notes on your device without a size cap.
Context menus (contextMenus)For the right-click items Save this page and Add selection….

Pinnook does not use content scripts, does not inject anything into web pages, does not request access to any website, and does not work in Incognito windows (so private browsing is never touched).

The free version contains no code that can make a network request, and its security policy blocks it from doing so. Read the full privacy policy.

Troubleshooting and FAQ

The panel does not open. Click the toolbar icon (pin it from the puzzle-piece menu). The side panel needs Chrome 114 or newer; Pinnook requires version 116 or newer.

“Pinnook keeps notes on web pages” message. The current tab is a browser page (like chrome://…), a local file or a blank tab. Open a normal website.

I typed a note but the library doesn't show it. Notes appear after the automatic save (a fraction of a second). Look for Saved ✓ under the note. The Library tab also hides pages that don't match your search, project or tag filter.

Will notes sync across my computers? Not in the free version, because nothing leaves your device. Use Export/Import, or Premium encrypted backup.

Does the same page on two sites share a note? No. A note belongs to one exact address (without tracking parameters and #anchors). https://a.com/x and https://www.a.com/x are different addresses.

What if the page's address changes? The note stays with the old address. Copy the text across, or add a link in the new page's note.

Is there a size limit? A single note holds up to 200 000 characters. The total is limited only by your disk.

Can I use it in Incognito? No, by design.

Does Pinnook work on Edge, Brave, Opera? It is built for Chrome. Other Chromium browsers that support the side panel API usually work; Google Drive sign-in for Premium needs Google Chrome (Dropbox works elsewhere).

How do I delete everything? Settings → Your data → Delete all Pinnook data, or simply uninstall Pinnook.

Known limitations

  • One note per page address; no folders inside projects.
  • Notes are plain Markdown text: no images, attachments or page screenshots.
  • Search is a simple "all words match" search (no fuzzy matching).
  • If you edit the same page's note on two devices between syncs, the newest edit wins as a whole (notes are not merged line by line).
  • Single-page web apps that change their content without changing the address share one note per address.

Getting help

  • Report a bug or ask a question: open an issue on the project's GitHub page (link in Settings → About).
  • Please do not include private notes or personal data in public issues.
