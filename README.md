# Pinnook – public support site

Pinnook is a local-first Chrome extension for private notes on web pages, by PinPixels.

- **Help:** https://pinpixels.github.io/pinnook/help.html
- **Privacy policy:** https://pinpixels.github.io/pinnook/privacy.html
- **Terms:** https://pinpixels.github.io/pinnook/terms.html
- **Report a bug or request a feature:** open an issue here (never paste private notes).
- **Security problems:** see SECURITY.md.

This repository hosts only the documentation site and the issue tracker. The extension's source code is private.
